# OpenFISH_MALDI_Protocol

The complete codes to reproduce the OpenFISH MALDI protocol.

We recommend using Conda (Miniconda or Anaconda) to create the following environments:

## 1. OpenFISH probe environment

```bash
conda create -n openFISH_probe python>=3.10
conda activate openFISH_probe
pip install -r env1_requirement.txt
```

Then, install NUPACK:  
[https://github.com/rwollman/NUPACK/tree/master/src/package](https://github.com/rwollman/NUPACK/tree/master/src/package)

## 2. OpenFISH gene panel environment

```bash
conda create -n openFISH_genepanel python==3.7.11
conda activate openFISH_genepanel
pip install -r env2_requirement.txt
```

## 3. OpenFISH decode environment

Install the correct GPU driver ([https://www.nvidia.com/en-us/drivers/](https://www.nvidia.com/en-us/drivers/)) and CUDA Toolkit ([https://developer.nvidia.com/cuda-downloads](https://developer.nvidia.com/cuda-downloads)) for your system. A GPU is recommended for image deconvolution, cell segmentation, and spot detection acceleration.

```bash
conda create -n openFISH_decode python==3.10.13
conda activate openFISH_decode
python -m pip install cellpose
pip install --no-deps m2stitch
```

Install `cucim` according to your CUDA version (Windows systems are not supported):

```bash
pip install cucim-cu12   # for CUDA 12
# pip install cucim-cu13 # for CUDA 13
pip install -r env3_requirement.txt
```

## 4. MALDI-related (optional but recommended)

We recommend following the [uMAIA tutorial](https://github.com/lamanno-epfl/uMAIA) to install related tools. After installing uMAIA, install napari inside the `uMAIA_env` using:

```bash
python -m pip install "napari[pyqt6,optional]"
```

Napari can also be installed as a [standalone application](https://napari.org/stable/getting_started/installation.html), which is an acceptable alternative.

## Jupyter Notebooks Explanation

Below is the explanation of each Jupyter notebook. It is recommended to follow the numerical order to go through the entire procedure. The required environment for each notebook and more details are provided in the markdown comments within the notebooks themselves.

- **01_RO_design.ipynb**: This notebook is used for readout (RO) probe generation. Each RO probe has a length of 20 nt. Ideally, using only three types of nucleotides can reduce the potential secondary structure of rolling circle amplification products. However, low complexity may become a hurdle for larger panel design. In such cases, all four bases can be used.

- **02_Bridge_design.ipynb**: This notebook is used for bridge generation. Each bridge has a length of 30 nt.

- **03_Padlock_join.ipynb**: Using the previously generated RO probes and bridges, this notebook assembles complete padlock probes. The key logic is to select five ROs corresponding to the five colors for one cycle, then choose bridges to form the full padlock. The design ensures that both ends of the padlock are exposed under hybridization conditions, and the total minimum free energy exceeds a defined threshold.

- **04_Panel_design.ipynb**: This notebook is used for panel design and codebook generation, assigning genes to cycles and coding colors.

- **05_Probe_design.ipynb**: This notebook consists of one main section for probe design and two optional helper sections for input preparation.

- **06_Decode.ipynb**: This notebook is used for OpenFISH decoding.

- **07_imzML_preprocess.ipynb**: Raw binary files generated by TIMS-TOF are first converted into imzML format using SCiLS Lab software. This notebook then uses uMAIA to convert the imzML file into an AnnData file.

- **08_Multiomics_registration.ipynb**: This notebook first generates a tiled reference image. Next, images are aligned outside the notebook using the Napari GUI. The alignment results are saved, and the notebook is then used to apply the transformation and transfer ion signals into single cells.

- **09_Signal_transfer.ipynb**: This notebook is used to transfer ion signals into single cells.

## Folder Structure Explanation

- **openDecode**: Contains codes used in `06_Decode.ipynb` for OpenFISH data decoding.
- **OpenDesign**: Contains codes used in `05_Probe_design.ipynb` for OpenFISH probe design.
- **RO_Pad_Design**: An empty folder to store files generated by `01_RO_design.ipynb`, `02_Bridge_design.ipynb`, and `03_Padlock_join.ipynb`.
- **SEQUENCES**: Contains necessary data required for `05_Probe_design.ipynb`.
